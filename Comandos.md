# Comandos básicos do git

git clone = clona o repositório para os arquivos locais do seu computador pessoal.

git status = apresenta as mudanças salvas ou não salvas no seu repositório.
Por exemplo, ele mostra quais arquivos foram modificados e/ou quais arquivos são novos.

git diff = mostra as mudanças que você fez localmente em seu repositório.
Por exemplo, ele vai mostrar as mudanças feitas dentro de um arquivo, alguma linha adicionada ou alterada.

git add . = adiciona todas as mudanças que você fez localmente para preparar para salvar elas.
Por exemplo, se fiz alterações em dois arquivos diferentes, ele adiciona as duas alterações ao commit.

git commit -m = salva todas as mudanças feitas localmente, deixando uma mensagem para a nova versão.

git push = envia as mudanças feitas localmente para o servidor, ou seja, envia as mudanças para o github.

git log = mostra o histórico de commits.

git pull = atualiza o repositório local com as mudanças feitas no servidor.
Por exemplo, se uma pessoa fez alterações e as enviou para o servidor, você usa o git pull para atualizar essas mudanças na sua máquina.



# Comandos básicos do Terminal

ctrl + shift + v = atalho para colar algo no terminal.

ctrl + shift + c = atalho para copiar algo no terminal.

ctrl + l = limpa o terminal.

ls = mostra as pastas.

cd = muda o diretório do terminal.



# Comandos básicos do vim

:q! = sai do vim sem salvar alterações.

:q = sai do vim só se não houver alterações não salvas.

:w = salva as alterações.

i = entra no modo de edição.

o = pula uma linha e entra no modo de edição.

.bashrc = mexe nas configurações básicas do sistema.

dd = deleta

x = apaga um caracter (fora do modo de edição)
